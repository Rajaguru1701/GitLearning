# Sakthi Clothes — Women's Fashion Boutique Website

A modern, fully responsive static website for **Sakthi Clothes**, a premium women's fashion boutique.

## 🌸 Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, featured collections, why choose us, CTA |
| About | `about.html` | Brand story, mission & vision, boutique gallery |
| Collections | `products.html` | Product gallery with category filter tabs |
| Contact | `contact.html` | Address, map, phone, social media links |

## 📁 Folder Structure

```
sakthi-clothes/
├── index.html
├── about.html
├── products.html
├── contact.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
```

## 🚀 How to Run

Simply open `index.html` in any modern browser — no server needed.

Or use VS Code Live Server extension for the best experience.

## 🌐 Hosting

Ready to deploy on:
- **Netlify**: Drag & drop the folder at [netlify.com](https://netlify.com)
- **GitHub Pages**: Push to a repo and enable Pages
- **Vercel**: Import the project at [vercel.com](https://vercel.com)

## 📱 APK / WebView

This site is WebView-compatible. Load `index.html` as the start URL in your Android WebView app.

## ✨ Tech Stack

- HTML5 + CSS3
- Bootstrap 5.3 (CDN)
- Bootstrap Icons (CDN)
- Google Fonts (Poppins, Playfair Display, Dancing Script)
- Vanilla JavaScript
- Unsplash CDN images
